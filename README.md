# VOLT Fitness

Персональный фитнес-трекер с недельным расписанием тренировок, пошаговым прохождением упражнений, замерами тела, фотографиями прогресса и аналитикой активности.

## Возможности

- динамический план домашнего этапа и тренировок с 4-й недели;
- отдельные чекбоксы упражнений для каждого круга;
- фото и краткие инструкции по технике;
- журнал тренировок и серия активности;
- ежедневные шаги, минуты активности и калории;
- замеры тела и сравнение фотографий «до/после»;
- адаптивный интерфейс для телефона и компьютера.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Хранилища

Приложение использует Cloudflare D1 для персональных данных и R2 для фотографий прогресса. Логические привязки указаны в `.openai/hosting.json`.

## GitHub Actions

Workflow `VOLT CI` запускается для push и pull request в `main`, устанавливает зависимости и проверяет production-сборку.
