# Volt

Production: https://ritmovis.duckdns.org/

Установка PWA доступна на экране входа и в профиле. Кнопка появляется, когда браузер предоставляет системный диалог установки.

**Сила в твоём ритме.**

Силовые, велосипед и плавание в одном персональном плане.
[Утверждённый бренд](docs/design-system/brand.md). Прежнее название — VOLT.

Автономный персональный фитнес-трекер: Next.js, локальная SQLite, локальное хранение фото и PWA. Cloudflare, ChatGPT, Google Fonts и внешние CDN не требуются.

Текущая карта документации и AI-спринтов:
[`docs/README.md`](docs/README.md).

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. При первом входе приложение предложит задать пароль для логина `Atlantik` (не менее 12 символов). База и фото создаются в `./data`.

## VPS

1. Установите Docker и Docker Compose.
2. Запустите `docker compose up -d --build`.
3. Поставьте перед приложением Nginx или Caddy с HTTPS и проксированием на `127.0.0.1:3000`.
4. Резервируйте Docker volume `volt-data` — в нём база и фотографии.

PWA устанавливается на Android из меню браузера после публикации по HTTPS. Для обновления: `git pull && docker compose up -d --build`.

## Безопасность

- пароль хешируется scrypt с индивидуальной солью;
- сессия хранится в `HttpOnly`, `SameSite=Strict` cookie, в БД лежит только SHA-256 токена;
- после пяти ошибок вход блокируется на 15 минут;
- API и фото недоступны без сессии;
- загрузки ограничены JPEG/PNG/WebP до 8 МБ и проверяются по сигнатуре;
- персональные API-ответы не кешируются.

Перед публичным запуском обязательно включите HTTPS, firewall, автоматические обновления ОС и регулярный backup volume.
