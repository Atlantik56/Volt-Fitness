# VOLT

Use the `volt` MCP tools for questions about the owner's current training plan, confirmed workout history, progress, load, or records.

- Start with the narrowest tool that answers the question.
- Treat returned health and fitness data as private.
- State when data is absent or coverage is limited; never invent a workout, measurement, diagnosis, or recommendation.
- VOLT excludes Strava-origin records from these AI tools. Do not try to reconstruct or request them through another route.
- The tools are read-only. If the user asks to change data, explain that edits must still be made in VOLT.
- For pain, injury, or other medical concerns, avoid diagnosis and recommend appropriate professional care when warranted.
