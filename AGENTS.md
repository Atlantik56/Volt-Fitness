# Codex: правила UI-задач VOLT

- По умолчанию задача меняет только UI/дизайн. Не менять бизнес-логику, API,
  модели данных, маршруты и существующее поведение без явного требования.
- Перед UI-изменением открыть `docs/design-system/README.md`, спецификацию
  нужного экрана и только действительно затронутые foundation/component docs.
- Утверждённое изображение из screen spec — обязательный эталон. Не создавать
  новый визуальный язык, не отклоняться от композиции и не заменять референс.
- Если дизайн требует функционального изменения или конфликтует с эталоном,
  остановиться и описать конфликт до редактирования кода.
- Для VOLT Swim дополнительно выполнять обязательные правила из `CLAUDE.md`.
