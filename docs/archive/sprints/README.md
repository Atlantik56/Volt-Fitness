# Архив завершённых и исторических спринтов

Статус: архив. Файлы в этой папке сохраняют принятые решения, handoff и историю
реализации прежних спринтов. Они не являются текущим планом работ.

## Содержимое

- `AI_HUB_HANDOFF.md` — исторический handoff по AI Hub, Anthropic, MWS GPT и
  связанным изменениям 26 июля 2026 года.
- `TRAINING_SESSION_REDESIGN.md` — проект редизайна режима тренировки,
  сохранённый для истории решений.
- `VOLT_COACH_DESIGN.md` — реализованный дизайн локального
  детерминированного Coach, включая Sprint 4 и Sprint 6.13.

## Правила использования

- Не выполнять задачи из архивных файлов повторно без сверки с актуальным кодом.
- Не считать статусы и пути в архиве актуальными автоматически.
- При поиске мотивации старого решения использовать архив как источник
  контекста, а не как техническое задание.
- Текущий порядок AI-работ находится в
  [`../../ROADMAP_AI.md`](../../ROADMAP_AI.md).
- Актуальные неизменяемые принципы находятся в
  [`../../AI_PRINCIPLES.md`](../../AI_PRINCIPLES.md).
