# Reference Implementation VOLT 2.0

Утверждённый экран Home — каноническая Reference Implementation и обязательный
визуальный ориентир для всего приложения VOLT 2.0:
[home-approved.png](assets/approved-screens/home-approved.png).

Новые экраны наследуют визуальный язык Home, а не создают собственные локальные
паттерны. Содержание, состояния и layout могут отличаться только там, где этого
требует функциональность. При этом экран должен восприниматься частью той же
системы и сохранять:

- официальный материал [VOLT Glass](05-glass-system.md);
- [App Background Architecture](01-design-principles.md#app-background-architecture);
- иерархию прозрачности и blur, обработку границ и глубину поверхностей;
- установленные [типографические роли](03-typography.md),
  [spacing и радиусы](04-spacing.md);
- [иерархию CTA](components/buttons.md), плотность и роли
  [карточек](components/cards.md);
- язык [Hero](components/hero.md): один доминирующий фокус и одно следующее
  главное действие;
- общие принципы композиции из
  [Design Principles](01-design-principles.md);
- спокойный функциональный [Motion System](06-motion.md).

Home задаёт язык материала, иерархии, ритма и композиции, но не требует
механически копировать набор секций или сетку независимо от назначения экрана.
Новая визуальная конструкция допустима только тогда, когда она обоснована
функциональностью или прямо предусмотрена явным design-contract rule.
Декоративное отличие, локальное удобство реализации или желание «освежить»
экран не являются достаточным основанием.

Если требование экрана невозможно реализовать в языке Home, необходимо сначала
зафиксировать функциональную причину или ссылку на применимое правило контракта.
Без такого обоснования используется существующее решение VOLT 2.0. Отдельный
явно утверждённый контракт имеет приоритет только внутри объявленной им области.

## Проверка соответствия

Перед утверждением нового экрана сравнить его с Home и проверить:

1. Материал, фон, прозрачность, blur, границы и радиусы принадлежат одной системе.
2. Типографика, spacing, card density и CTA hierarchy сохраняют тот же ритм.
3. Hero и общая композиция имеют ясный главный фокус без конкурирующего шума.
4. Все отличия от Home объясняются функцией или явным правилом дизайн-контракта.
