# Не делать

- Не менять утверждённую концепцию, палитру, сетку, hero или navigation без
  явного запроса.
- Не добавлять новые цвета, radius, shadow, blur, spacing или motion локально.
- Не создавать обычные белые карточки, random neon, holograms, тяжёлый glow,
  частицы, confetti или бесконечную фоновую анимацию.
- Не строить dashboard из множества равноценных карточек и CTA.
- Не выдумывать данные, метрики, советы Coach, достижения или состояния.
- Не передавать смысл только цветом, hover, motion или жестом.
- Не заменять эталонный файл похожим изображением и не редактировать его молча.
- Не читать и не переписывать всю документацию, если задача ограничена одним экраном.
