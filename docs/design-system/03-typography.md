# Типографика

Текущая реализация использует современный sans-serif и сильную иерархию:
page title → hero value/title → section title → body → metadata. Крупные метрики
получают компактные единицы; вторичный текст остаётся читаемым.

## Правила

- Использовать существующий шрифтовой стек и размеры роли, а не локальные стили.
- Заголовок описывает содержание, eyebrow — контекст, metadata — уточнение.
- Не использовать italic, outline или uppercase как единственный способ задать
  иерархию; эти приёмы допустимы только там, где уже утверждены.
- Число и единица визуально связаны; label и период обязательны для метрики.
- Обычный текст должен соответствовать WCAG 2.2 AA; не уменьшать вторичный текст
  ради плотности.

Отдельная новая шкала размеров пока не утверждена. До её появления переиспользовать
существующие роли из реализации.
