# VOLT

Публичное имя **VOLT** восстановлено по запросу пользователя 2026-10-07.
Основной домен: **https://volt-trainer.duckdns.org/**.

- Названия модулей: VOLT Swim, VOLT Cycling, VOLT Coach.
- Девиз: «Сила в твоём ритме.».
- Возвращены исходные VOLT-иконки установки и Open Graph из Git до переименования.
- Общий фон использует существующий исходник с надписью VOLT; композиция,
  палитры модулей и текущие пользовательские сценарии сохраняются.
- RITMOVIS был публичным именем с 2026-09-05. Это историческое решение
  остаётся в Git и утверждённых материалах той итерации.

## Совместимость

Переименование касается отображаемого бренда, PWA, метаданных и уведомлений.
Идентификаторы программ и тренировок, снимки истории, база SQLite, cookies,
localStorage, маршруты и Git-репозиторий сохраняются. История не переписывается.
Отображение старых имён выполняет существующая trainingLabelRu.

Домены имеют отдельные cookies, push-подписки и установленные PWA. На основном
домене может потребоваться повторный вход и включение уведомлений. Установка
RITMOVIS не переезжает автоматически на другой origin.
