# Отступы и сетка

VOLT использует стабильный content grid, повторяемые края и равномерный ритм
между секциями. Карточки одной роли имеют одинаковые внутренние отступы, радиус
и gap. Точные значения берутся из существующих компонентов и CSS.

## Правила

- Не вводить новую spacing-шкалу в рамках локальной правки.
- Один уровень вложенности должен быть заметен через структуру, а не случайный gap.
- Desktop sidebar и content inset сохраняются; на mobile контент становится
  одноколоночным и учитывает fixed navigation.
- Touch target — не меньше `44×44px`.
- Проверять ширины `360`, `390/412`, `768`, `1024`, `1280` и `1440px`, zoom 200%.
- Не допускать горизонтальный overflow, обрезанные единицы и наложение навигации.
