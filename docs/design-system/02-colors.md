# Цветовая система

Текущие базовые токены реализации находятся в `app/globals.css`:

| Роль | Текущее значение | Назначение |
|---|---|---|
| Background | `#090b0d` | фон приложения |
| Panel | `#111417` | базовые поверхности |
| Line | `#24282c` | границы и разделители |
| Text | `#f4f6f5` | основной текст |
| Muted | `#8e969d` | вторичный текст |
| Primary lime | `#c7ff32` | основной CTA, active, прогресс |
| Orange | `#ff7849` | семантическая/категорийная роль |
| Blue | `#4d9cff` | семантическая/категорийная роль |
| Violet | `#a78bfa` | семантическая/категорийная роль |

Не копировать hex в компоненты: использовать семантические токены. Lime не
превращать в фоновую заливку больших областей и не использовать для каждого
акцента. Warning, error и success — только семантика.

## VOLT Swim

Swim использует deep navy/near-black основу, electric blue как primary и
cyan/turquoise как secondary. Это локальная утверждённая палитра модуля, а не
разрешение перекрасить общий shell. Точные новые значения не фиксировать без
утверждения; следовать [`../volt-swim/VOLT_SWIM_DESIGN_CONTRACT.md`](../volt-swim/VOLT_SWIM_DESIGN_CONTRACT.md).
