# Nutrition

## Назначение и композиция

Nutrition помогает видеть питание и делать следующий полезный выбор без
давления. Использовать текущие meal rows/cards, дневные показатели и ясную
иерархию факта, цели и оставшегося значения. Empty state предлагает добавить
реальные данные.

Не выдумывать приёмы пищи, калории или персональные советы. Семантический warning
не использовать как оценку человека; AI-рекомендация показывает основания и
не заменяет расчёты продукта.
