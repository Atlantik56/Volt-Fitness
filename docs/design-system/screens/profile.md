# Profile

## Назначение и композиция

Profile объединяет персональные данные, цели, настройки и управляемые пользователем
материалы. Использовать существующие формы, секции и сравнения; чувствительные
действия отделять и подтверждать. Сохранение показывает success/error без потери
введённых данных.

Не показывать личные данные в декоративных блоках, не менять цели и настройки
автоматически, не использовать загруженные изображения вне их утверждённой роли.
