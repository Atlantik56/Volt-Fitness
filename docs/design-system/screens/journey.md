# Journey

## Назначение и композиция

Journey показывает долгосрочный путь и помогает замечать реальный прогресс.
Сохранять существующую последовательность этапов, milestones и подтверждённых
показателей. Доминирует текущий этап/следующий достижимый шаг, а не декоративная
«геймификация».

Не создавать достижения из отсутствующих данных, не использовать давление,
ложную срочность или сравнение с другими людьми.
