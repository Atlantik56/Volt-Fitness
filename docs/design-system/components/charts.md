# Charts

График отвечает на конкретный вопрос и всегда содержит title, период, единицы,
legend и доступное текстовое резюме/таблицу.

- Использовать line, area-range или bars только по смыслу данных.
- План/факт различать не только цветом, но и формой/штрихом.
- Показывать пробелы данных честно; не интерполировать их как реальные значения.
- Избегать лишних gridlines, декоративных линий, 3D и псевдонаучных radar charts.
- Не показывать фальшивую точность и не генерировать значения для заполнения макета.
- На mobile упрощать подписи; горизонтальный скролл допустим только если иначе
  теряется смысл.
