# Buttons

## Роли

- Primary: одно главное действие блока; lime в общем VOLT, утверждённый primary
  accent внутри Swim.
- Secondary: равноценное, но не главное продолжение.
- Ghost: компактное вспомогательное действие.
- Danger: только разрушительное действие, обычно после подтверждения.

Обязательны idle, hover, focus, pressed, loading и disabled. Кнопка имеет явный
label, keyboard semantics и touch target `44×44px`. Не вкладывать кнопку в другую
интерактивную поверхность и не ставить несколько доминирующих CTA рядом.
