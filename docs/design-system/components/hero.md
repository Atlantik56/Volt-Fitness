# Hero

Hero — единственный доминирующий блок страницы. Он показывает текущий контекст,
главную цель/ценность, статус и одно следующее действие.

- Не заменять hero обычной безликой карточкой, если он уже утверждён для экрана.
- Фоновое изображение или эффект не снижает читаемость; использовать локальный overlay.
- Не создавать два конкурирующих hero на одной странице.
- На mobile сохранить смысл и CTA, меняя композицию без потери функций.
- Поддержать loading, ready, unavailable и complete, если применимо.

Для Swim использовать роли `workout`, `program`, `progress`, `completion` из
[`../../design/COMPONENTS.md`](../../design/COMPONENTS.md).
