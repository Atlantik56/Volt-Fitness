# Navigation

Desktop использует единый глобальный VOLT sidebar; mobile — единый bottom bar.
Активное состояние имеет текстовый/структурный признак и не зависит только от цвета.

Контекстная навигация допустима внутри раздела, но не создаёт второй app shell,
конкурирующий логотип или дубли глобальных destinations. Для Swim утверждены:
Главная, План тренировок, История, Аналитика, Рекорды, AI Coach.

Навигация доступна с клавиатуры, имеет видимый focus и не скрывает контент на
малых экранах. Изменение глобальной структуры требует явного запроса.
