# Dialogs

Dialog или modal используется для сфокусированного действия, подтверждения или
короткого режима, а не как контейнер целой новой страницы.

- Ясные title, действие закрытия и один primary CTA.
- Destructive действие требует явного подтверждения.
- Focus помещается внутрь, удерживается там и возвращается инициатору после закрытия.
- Escape закрывает безопасный dialog; фон не остаётся интерактивным.
- На mobile dialog помещается в viewport, прокручивается внутри и не перекрывается
  системной/bottom navigation.
- Ошибка сохраняет введённые данные и объясняет восстановление.
