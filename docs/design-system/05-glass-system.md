# Glass System 2.0

Стекло создаёт глубину, но не заменяет контраст и структуру.

Действующий фон обычного VOLT:
[volt-trisport.webp](../../public/backgrounds/volt-trisport.webp). Для изучения
деталей доступен [PNG-исходник](../../public/backgrounds/volt-trisport.png).

## Утверждённые свойства

- тёмная полупрозрачная поверхность;
- тонкая граница и сдержанный inner highlight;
- мягкая тень без тяжёлого чёрного «парения»;
- blur только там, где фон остаётся контролируемым;
- glow только для active, selected или primary-action состояния;
- согласованные радиусы для одинаковых ролей.

Текст и данные должны сохранять контраст без backdrop-filter. Предусмотреть
fallback для reduced transparency/производительности. Не анимировать blur,
большие тени или полноэкранные градиенты покадрово.

Поверх фона использовать существующий тёмный overlay из реализации. Не менять
кадрирование, яркость и контраст глобально без проверки всех страниц; на mobile
сохранять утверждённую точку фокуса и более плотное затемнение.

Для Swim фон и водные эффекты описаны в [`../design/VOLT_SWIM.md`](../design/VOLT_SWIM.md);
люди, пловцы и части тела в фоне запрещены.
