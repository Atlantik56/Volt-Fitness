## Статус

Все девять утверждённых desktop-изображений добавлены из локальных экспортов. Общий исходник экранов Records и AI Coach разделён по границе макетов без повторной генерации.

Нельзя заменять утверждённые изображения «похожими» версиями: ранее отклонённые варианты содержали людей, лишние мобильные окна или артефакты графиков.
