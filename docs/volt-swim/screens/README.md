# Approved Screen Manifest

Эта папка предназначена для утверждённых desktop-изображений.

Ожидаемые имена файлов:

```text
01-home.png
02-training-plan.png
03-workout-details.png
04-todays-workout.png
05-workout-completion.png
06-history.png
07-analytics.png
08-records.png
09-ai-coach.png
```

## Статус

Ветка и текстовый дизайн-контракт созданы. Бинарные изображения нужно добавить отдельным шагом из локальных экспортов утверждённых макетов, сохранив указанные имена без повторной генерации.

Нельзя заменять утверждённые изображения «похожими» версиями: ранее отклонённые варианты содержали людей, лишние мобильные окна или артефакты графиков.
