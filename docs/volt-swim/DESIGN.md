# VOLT Swim 1.0 — дизайн-система

Канонический подробный контракт: [`../design/VOLT_SWIM.md`](../design/VOLT_SWIM.md).
Этот документ фиксирует практические правила текущей реализации.

## Иерархия

Каждая страница использует одну последовательность: общий `SwimShell`, header,
локальная навигация, один featured-блок и компактные вторичные секции. История
— основной визуальный эталон: контент рассказывает о тренировках и прогрессе,
а не складывается в равномерную dashboard-сетку.

## Glass и акцент

- Базовая поверхность: полупрозрачный сине-чёрный градиент, blur `18px`,
  внутренний свет сверху и одна спокойная глубокая тень.
- Радиусы: `12px` для внутренних контролов, `16px` для стандартной карточки,
  `20px` для hero/featured-поверхности.
- Основной структурный акцент — `#21cfff`: active/focus, дорожка, маркер,
  ключевая серия графика. Зелёный используется только для подтверждённого
  успеха, а не как второй декоративный акцент.
- Pool-lane мотив допустим один раз в hero или timeline и не пересекает текст.

## Ритм и карточки

- Базовый внутренний отступ карточки: `16–24px`; между секциями — `28px`.
- Одна featured-карточка задаёт контекст; вторичные карточки компактнее и не
  обязаны иметь одинаковую высоту.
- Loading сохраняет геометрию; empty/error/unavailable объясняют причину и
  следующий доступный шаг. Отсутствующие значения отображаются как `—` или
  «Недоступно», но не как ноль.
- Hover только усиливает глубину на устройствах с hover. Focus всегда видим,
  press короткий, touch target — минимум `44×44px`.

## Responsive

- `≤420px`: узкий mobile, одна колонка, длинные группы метрик раскрываются
  вертикально.
- `421–820px`: mobile/tablet без sidebar; навигация остаётся горизонтально
  прокручиваемой, карточки не сжимаются в desktop-колонки.
- `821–1024px`: tablet/compact desktop; сложные hero и masonry упрощаются.
- `1025–1280px`: основной desktop.
- `1281–1440px+`: широкая композиция с ограниченной длиной текста и без
  искусственного растягивания карточек.

Контрольные ширины QA: `360`, `390`, `768`, `1024`, `1280`, `1440px`.

## Запрещено

Admin/KPI-таблицы как основная композиция, равномерная мозаика одинаковых
карточек, тяжёлые рамки, постоянный neon/pulse, декоративные пустые графики,
данные только через hover, скрытие функций на mobile и новый локальный стиль
в обход общих токенов/компонентов.
