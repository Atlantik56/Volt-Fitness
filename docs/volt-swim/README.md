# VOLT Swim — Approved Design Kit

Статус: **утверждённая дизайн-концепция**

VOLT Swim — большой раздел внутри единого приложения VOLT, а не отдельное приложение. Глобальная навигация VOLT сохраняется на всех экранах; внутри раздела используется контекстная навигация Swim.

## Утверждённые экраны

1. `Design v1.0` — Главная
2. `Design v1.1` — План тренировок
3. `Design v1.2` — Детали тренировки
4. `Design v1.3` — Сегодняшняя тренировка / запуск
5. `Design v1.4` — Завершение тренировки
6. `Design v1.5` — История тренировок
7. `Design v1.6` — Аналитика
8. `Design v1.7` — Рекорды
9. `Design v1.8` — AI Coach

## Ключевые правила

- Никаких людей, пловцов или человеческих силуэтов в интерфейсе и фонах.
- Фон связан с бассейном: дорожки, глубина, подводный свет, отражения.
- Тёмная премиальная палитра с синими и бирюзовыми акцентами.
- Glassmorphism используется системно, а не декоративно.
- Главная задача интерфейса — читаемость и спокойствие, а не демонстрация эффектов.
- Mobile-адаптив не фиксируется отдельными артбордами: его должен реализовать Codex на основе desktop-контракта.

## UX-сценарий тренировки

1. Пользователь открывает сегодняшнюю тренировку.
2. Нажимает **«Начать тренировку»**.
3. VOLT запускает общий таймер и переводит тренировку в активное состояние.
4. Телефон можно убрать; Garmin записывает фактические метрики.
5. После бассейна пользователь нажимает **«Завершить тренировку»**.
6. FIT-данные импортируются и используются на экране подтверждения.
7. VOLT сравнивает план и факт, показывает метрики и комментарий AI Coach.
