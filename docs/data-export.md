# Экспорт пользовательских данных

В профиле, в «Интеграции и данные», кнопка «Экспорт данных» скачивает JSON версии 1.
Файл содержит профиль, все подтверждённые тренировки, измерения, дневную активность и метаданные фотографий. Сами изображения скачиваются отдельно из существующего интерфейса фотографий. Экспорт тренировок за период в CSV/JSON в аналитике сохраняется.

GET /api/data-export требует действующую сессию и возвращает private/no-store attachment. Данные читаются одной SQLite-транзакцией. В выгрузку не входят API-ключи, cookies, сессии, OAuth-токены, хеши пароля и внутренние имена файлов. Это пользовательская выгрузка, не резервная копия всей БД и не формат автоматического восстановления.
