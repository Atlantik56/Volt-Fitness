## Execution rule

1. Confirm the requested sprint or bounded outcome.
2. Check current code and the canonical roadmap; document paths are guidance,
   not permission to edit every listed file.
3. Complete only that scope and its relevant validation.
4. Update the canonical status only with verified facts.
5. Stop before the next sprint and report the diff, checks and open questions.

If the roadmap and implementation disagree, report the mismatch instead of
silently choosing a new scope.
