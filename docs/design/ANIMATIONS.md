# VOLT Swim — motion-контракт

Motion поддерживает ориентацию, подтверждает действие и передаёт спокойное
ощущение воды. Он не маскирует ожидание и не становится главным содержимым.

## Токены

| Токен | Значение | Применение |
|---|---:|---|
| `motion-instant` | `80ms` | press/локальный feedback |
| `motion-fast` | `160ms` | hover, focus, icon/state |
| `motion-base` | `240ms` | panel, tab, step transition |
| `motion-slow` | `400ms` | hero/result reveal, progress |
| `ease-standard` | `cubic-bezier(.2,.8,.2,1)` | обычные переходы |
| `ease-out` | `cubic-bezier(.16,1,.3,1)` | появление/завершение |

Значения должны быть общими токенами реализации. Новая длительность требует
обоснованного сценария, а не вкусовой настройки компонента.

## Допустимо

- fade + translate до `8px` при смене секции/шага;
- crossfade контента одинаковой роли;
- контролируемое заполнение Progress Track после подтверждённого прогресса;
- короткий ripple внутри нажатой поверхности, ≤ `400ms`, без выхода за границы;
- слабый shimmer по Progress Track или hero однократно после загрузки;
- caustics как почти статичный фон с очень медленным смещением, только если это
  не создаёт расход батареи/падение FPS;
- обновление метрики через crossfade; числа таймера меняются без прыжка layout.

## Ограничения

- Одновременно: не более одного ambient-эффекта и одного feedback-эффекта.
- Transform/opacity предпочтительнее layout/paint-анимаций. Не анимировать
  blur, большие тени и полноэкранные градиенты на каждом кадре.
- Hover не является обязательным способом узнать состояние. Touch получает
  эквивалентный pressed-feedback.
- Анимация не задерживает navigation, сохранение, старт/паузу таймера и показ
  ошибки. Она прерываема и не блокирует повторное действие.
- Бесконечные частицы, волны, параллакс, bouncing/spring, glow-pulse, confetti,
  автоскролл и motion поверх текста запрещены.

## Сценарии

| Событие | Эффект | Максимум |
|---|---|---:|
| Открытие страницы | fade контента, без каскада карточек | `240ms` |
| Смена вкладки | indicator + crossfade | `240ms` |
| Start/pause/resume | pressed + ясная смена состояния | `160ms` |
| Следующий интервал | crossfade + translate ≤ 8px | `240ms` |
| Завершение блока | Progress Track fill | `400ms` |
| Новая метрика | crossfade value | `240ms` |
| Coach insight | обычное появление panel | `240ms` |
| Завершение Foundation | hero reveal, без confetti | `400ms` |

## Reduced motion и доступность

При `prefers-reduced-motion: reduce`:

- отключить translate, parallax, ripple, shimmer, caustics movement и
  автоматическое плавное прокручивание;
- сократить переходы до `0–80ms` opacity либо сделать смену мгновенной;
- сразу показать конечное значение progress/метрики;
- сохранить все статусы, подтверждения и ориентацию без зависимости от motion.

Нельзя мигать чаще трёх раз в секунду. Focus ring появляется мгновенно. Таймер
не должен создавать live-region announcement каждую секунду.

## Проверка

- проверить нормальный и reduced-motion режимы;
- проверить слабое устройство/mobile: нет заметного jank и перегрева;
- проверить background/foreground таймера и быструю серию действий;
- убедиться, что отключение CSS/WAAPI-анимации не ломает состояние;
- зафиксировать в PR видео/скриншоты только для новых motion-паттернов.
